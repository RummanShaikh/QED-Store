# E-Commerce React Application

This is a React-based e-commerce web application where users can browse products, view product details, and manage their shopping cart.

## Deployed Website

Visit the live application here: [E-Commerce Website](https://6772ab988b0d2395a73b2038--rummanqed42assignment.netlify.app/)

---

## Features

- **Product Listing**: Displays a list of products fetched from the Fake Store API.
- **Product Details**: View detailed information about a specific product.
- **Cart Management**: Add, update, and remove products from the cart.
- **Responsive Design**: Optimized for various screen sizes.
- **Loading Spinner**: Indicates loading state for better UX.

---

## Technologies Used

- **Frontend**: React, React Router, CSS
- **API**: Fake Store API (`https://fakestoreapi.com/products`)
- **Deployment**: Netlify
